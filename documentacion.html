Acceso al Repositorio e Instalación

Para el presente semestre (2026-2), el código oficial se encuentra en la rama semestre-2026-2 del repositorio robertoasin/cacho-cpp. Es indispensable trabajar sobre esta rama, ya que tanto la firma de Jugador::jugar como el orden de los atributos de Actuacion / Anotacion y las reglas de puntuación han sido actualizados.

Terminal 
# 1. Clonar directamente la rama del semestre 2026-2
git clone -b semestre-2026-2 --single-branch https://github.com/robertoasin/cacho-cpp.git
cd cacho-cpp

# 2. Compilar y ejecutar la simulación en consola
cd src
make
./cacho
Importante sobre versiones previas: Si ya habías clonado el repositorio anteriormente, asegúrate de cambiar a la rama correcta ejecutando git fetch origin && git checkout semestre-2026-2. Los jugadores implementados con la interfaz del semestre anterior no compilarán ni funcionarán en esta versión.

Reglas del Juego y Novedades 2026-2

El simulador implementa las reglas de competencia Alalay de Cacho con una nueva condición estratégica para este semestre: el Bono de Chicas (+40 puntos).

Dinámica del Turno (2 Intentos)

Cada turno de un jugador consta de hasta 2 intentos independientes, y cada intento permite hasta 2 lanzamientos:

  • En el Intento 1, el jugador puede anotar directamente en su marcador ("anotar") o reservar su jugada sobre la mesa ("sobre").
  • En el Intento 2, si ya anotó en el Intento 1, puede anotar una segunda jugada o pasar ("nada"). Si dejó una jugada "sobre", debe elegir entre confirmar esa jugada reservada (" (de la 1ra mano)") o anotar lo obtenido en el segundo intento.
  • En el segundo lanzamiento de cada intento se aplican automáticamente hasta 2 vuelques de dados a su cara opuesta (suma 7: 1↔6, 2↔5, 3↔4).

Nuevo: Bono de Chicas (+40 pts)

Para fomentar mayor variedad de estrategias entre buscar jugadas mayores (Grandes/Póker) o consolidar la parte superior del tablero, se incorpora el Bono de Chicas:

Si un jugador logra anotar al menos 3 dados en cada una de las 6 chicas:
balas ≥ 3, tontos ≥ 6, trenes ≥ 9, cuadras ≥ 12, quinas ≥ 15 y senas ≥ 18,
recibe automáticamente +40 puntos adicionales en su puntaje total (marcador.bonoChicas = true).

"poker" Mayor 45 pts (4 iguales de mano) 40 pts (formado con vuelques) 45 pts (de mano) cuenta para Alalay
"grande" / "grande2" Mayor 50 pts (o Victoria por "dormida") 50 pts (5 iguales usando hasta 2 vuelques) Ambas en 50 pts requeridas para Alalay
Victorias Instantáneas y "Se Respeta":
  • Dormida (accion == "dormida"): 5 dados exactamente iguales sin volcar en un tiro de 5 dados gana la partida automáticamente.
  • Alalay (marcador.tieneAlalay()): Tener las 2 Grandes anotadas (50 y 50) junto con las 3 Mayores de mano (25, 35, 45) o bien las 6 Chicas con 4 dados (4, 8, 12, 16, 20, 24) otorga victoria inmediata.
  • Se Respeta (seRespeta == true): Si en el primer tiro obtienes de mano una jugada mayor (escalera, full o poker) que ya tienes anotada y aún no has respetado en la partida, se habilita una acción "lanzar" los 5 dados con seRespeta = true que no consume tu lanzamiento de mano.

Clase Base Jugador (Interfaz del Bot)

Para crear un agente o bot competidor, debes heredar de la clase abstracta Jugador definida en src/Jugador.h e implementar el método virtual puro jugar(...). Nota el nuevo orden de los parámetros para el semestre 2026-2:

src/Jugador.h 
class Jugador {
public:
    std::string nombre;
    int intento;       // Intento actual dentro del turno (1 o 2)
    int turno;         // Número de turno actual
    int lanzamiento;   // Lanzamiento actual dentro del intento (1 o 2)

    Jugador(std::string nom = "generico") 
        : nombre(nom), intento(0), turno(0), lanzamiento(0) {}

    virtual ~Jugador() = default;

    // Método principal que debe implementar cada estudiante (Orden 2026-2):
    virtual int jugar(const std::vector<int>& dados,
                      const std::vector<Actuacion>& actuacionesPosibles,
                      const std::map<std::string, Marcador>& marcadores,
                      const Anotacion& resultadoPrevio) = 0;
};

Parámetros de Jugador::jugar

  • 1. dados (const std::vector<int>&)
    Vector de 5 enteros (valores del 1 al 6) con las caras actuales de los 5 dados en la mesa.
  • 2. actuacionesPosibles (const std::vector<Actuacion>&)
    Lista de todas las acciones legales disponibles en el estado actual. Tu método jugar debe retornar un índice entero válido entre 0 y actuacionesPosibles.size() - 1.
  • 3. marcadores (const std::map<std::string, Marcador>&)
    Diccionario con las planillas de todos los jugadores de la partida. Puedes consultar tu propio marcador mediante marcadores.at(this->nombre) y también inspeccionar el puntaje de tus rivales.
  • 4. resultadoPrevio (const Anotacion&)
    Si en el Intento 1 elegiste la acción "sobre", en el Intento 2 este parámetro contiene la Anotacion reservada (en caso contrario, resultadoPrevio.puntos == -1).

Clase Marcador

Definida en src/Marcador.h, representa la planilla de puntuaciones de un jugador, incluyendo el estado del nuevo Bono de Chicas (+40 pts).

src/Marcador.h 
class Marcador {
public:
    int porAnotar;                         // Casilleros restantes por llenar (inicia en 11)
    std::map<std::string, int> puntajes;   // Mapa categoría -> puntos (-1 si no está anotada)
    bool dormida;
    bool panzaDeOro;
    bool bonoChicas;                       // true cuando se activó el Bono de Chicas (+40 pts)
    bool escaleraRespetada;
    bool fullRespetado;
    bool pokerRespetado;
    int suma;                              // Puntaje total acumulado (incluye +40 si bonoChicas == true)

    static constexpr int PUNTOS_BONO_CHICAS = 40;

    bool yaAnotado(const std::string &juego) const;
    bool tieneBonoChicas() const;
    bool tieneAlalay() const;
    bool marcadorIncompleto() const;
};

Estructura Anotacion

Anotacion es un struct plano que describe un puntaje asignado (o a asignar) en un determinado casillero de la cartilla o marcador del jugador. Nota que en la versión 2026-2 el atributo puntos se declara antes que juego:

src/Actuacion.h 
struct Anotacion {
    int puntos;         // Puntos obtenidos (-1 indica no aplica, 0 indica borrado)
    std::string juego;  // Nombre de la categoría de puntaje
};

Miembros de la Estructura

  • puntos (int)
    La puntuación correspondiente a la categoría.
    • Puntaje positivo: El puntaje calculado según las reglas (p. ej., 20/25 puntos para escalera, 30/35 para full, 40/45 para póker, 50 para grande, o el total sumado de dados repetidos para las chicas).
    • Valor 0: Significa que la categoría ha sido "tachada" o "borrada" en el tablero debido a una mala tirada.
    • Valor -1: Representa que la anotación no aplica a la jugada actual (por ejemplo, cuando la acción es "lanzar").
  • juego (std::string)
    Identificador de la jugada del tablero. Los valores posibles son:
    • Chicas: "balas" (unos), "tontos" (doses), "trenes" (treses), "cuadras" (cuatros), "quinas" (cincos), "senas" (seises). Si todas alcanzan al menos 3 dados, se activa el Bono de Chicas (+40 pts).
    • Mayores: "escalera", "full", "poker", "grande" (primer grande), "grande2" (segunda grande).
    • Especiales: Categorías temporales con aclaraciones como "juego_name (de la 1ra mano)".

Clase Actuacion

La clase Actuacion empaqueta todos los detalles de una acción posible devuelta por el sistema de reglas del juego a través de la clase Anotador. En la versión 2026-2 el orden de los atributos y del constructor es (indiceDados, anotacion, seRespeta, accion):

src/Actuacion.h 
class Actuacion {
public:
    std::vector<int> indiceDados;   // Índices de los dados [0-4] involucrados en la acción
    Anotacion anotacion;            // Estructura Anotacion asociada
    bool seRespeta;                 // Indica si la acción es parte de respetar una jugada
    std::string accion;             // Tipo de acción ("lanzar", "anotar", "sobre", "nada", "dormida")

    // Constructor
    Actuacion(std::vector<int> idx, Anotacion anot, bool respeta, std::string acc)
        : indiceDados(idx), anotacion(anot), seRespeta(respeta), accion(acc) {}

    void display() const;
    void displayCompacto(int indice = -1) const;
};

Miembros de la Clase

  • indiceDados (std::vector<int>)
    Vector con valores en el rango [0-4] que indica cuáles dados están involucrados en la acción. En una acción de tipo "lanzar", este vector especifica exactamente cuáles dados volverá a tirar el motor del juego.
  • anotacion (Anotacion)
    Estructura que describe cuántos puntos y qué categoría del tablero se ven afectados por la acción (mayormente para "anotar", "sobre" o tachar).
  • seRespeta (bool)
    Variable booleana. Si es true, se indica que la tirada actual respeta una jugada mayor de mano ya anotada previamente. Si es false, no se aplica respeto automático.
  • accion (std::string)
    Describe el comportamiento semántico de esta jugada:
    • "lanzar": El jugador desea volver a tirar los dados indicados en indiceDados.
    • "anotar": El jugador decide registrar la jugada en su tablero.
    • "sobre": Acción válida únicamente en el intento 1, donde el jugador reserva temporalmente una anotación para decidir en el segundo intento si conservarla o mejorarla.
    • "dormida": Declaración de victoria inmediata (dormida) al obtener 5 dados iguales del mismo valor de una sola tirada.
    • "nada": Comportamiento nulo o de control en turnos especiales (como segundas pasadas de tiro cuando ya se anotó en el intento 1).

Métodos Integrados

  • display() const
    Imprime los detalles de la actuación en múltiples líneas en la salida estándar std::cout. Útil para depuración y visualización de menús para jugadores humanos.
  • displayCompacto(int indice = -1) const
    Imprime la representación formateada en una sola línea del objeto. Si se pasa un valor positivo a indice, se antepone dicho valor entre corchetes, p. ej. [i]. Este formato es el utilizado principalmente por el motor de juego interactivo en consola.

Ejemplos Básicos de Uso en C++

A continuación se presentan diferentes ejemplos prácticos que ilustran cómo inicializar y manipular estos componentes en un flujo real de C++ con la interfaz del semestre 2026-2.

Cómo crear instancias directas de Anotacion y Actuacion usando inicializadores directos y constructores:

main.cpp 
#include "Actuacion.h"
#include <iostream>
#include <vector>

int main() {
    // 1. Instanciar una anotación directa de Full de Mano (35 puntos)
    Anotacion fullMano = {35, "full"};

    // 2. Crear una actuación para anotar el Full en la planilla
    Actuacion accionAnotar({}, fullMano, false, "anotar");

    // 3. Crear una actuación para lanzar los dados en las posiciones 0, 2 y 4
    Anotacion sinAnotar = {-1, ""};
    Actuacion accionLanzar({0, 2, 4}, sinAnotar, false, "lanzar");

    // 4. Crear una actuación para tachar/borrar la categoría "grande"
    Actuacion accionTachar({}, {0, "grande"}, false, "anotar");

    return 0;
}

Ejemplo de cómo un Bot evaluador implementa la nueva firma de jugar(...) y analiza las actuaciones posibles:

JugadorHeuristico.h 
#include "Jugador.h"
#include <iostream>
#include <vector>

class JugadorHeuristico : public Jugador {
public:
    JugadorHeuristico(std::string nom) : Jugador(nom) {}

    int jugar(const std::vector<int>& /*dados*/,
              const std::vector<Actuacion>& actuacionesPosibles,
              const std::map<std::string, Marcador>& /*marcadores*/,
              const Anotacion& /*resultadoPrevio*/) override {
        
        // Estrategia heurística básica:
        // 1. Si existe una victoria inmediata ("dormida"), tomarla inmediatamente.
        for (size_t i = 0; i < actuacionesPosibles.size(); ++i) {
            if (actuacionesPosibles[i].accion == "dormida") {
                std::cout << nombre << " declara DORMIDA y gana!" << std::endl;
                return i;
            }
        }

        // 2. Si hay una opción para anotar una jugada de alto valor (>= 30 pts) de manera directa
        for (size_t i = 0; i < actuacionesPosibles.size(); ++i) {
            if (actuacionesPosibles[i].accion == "anotar" && 
                actuacionesPosibles[i].anotacion.puntos >= 30) {
                return i;
            }
        }

        // 3. De lo contrario, por defecto volver a lanzar dados (generalmente la primera opción de lanzamiento)
        for (size_t i = 0; i < actuacionesPosibles.size(); ++i) {
            if (actuacionesPosibles[i].accion == "lanzar") {
                return i;
            }
        }

        // 4. Retorno de emergencia (último elemento disponible)
        return actuacionesPosibles.size() - 1;
    }
};
